# چوکو بار — پیاده‌سازی React از فایل فیگما

React 18 + TypeScript + Vite + React Router + CSS Modules، راست‌به‌چپ (RTL) با فونت Vazirmatn.

## اجرا

```bash
npm install
npm run assets   # تصاویر و آیکون‌ها را از فیگما در public/assets دانلود می‌کند
npm run dev
```

> لینک‌های asset فیگما حدود ۷ روز (تا حدود ۳۱ اکتبر ۲۰۲۶) معتبرند. اگر منقضی شدند، همان فایل‌ها را با همین نام‌ها از فیگما
> Export کنید و در `public/assets` بگذارید — فهرست کامل نام‌ها در `scripts/figma-assets.json` است.

## صفحه‌ها

| مسیر | فریم فیگما |
|---|---|
| `/` | کالکشن شیرینی‌ها |
| `/product/:slug` | صفحهٔ محصول (کروسان، اشترودل، پن او شکلا، دانمارکی، رول دارچین) |
| `/cart` | سبد خرید |
| `/checkout/shipping` | اطلاعات و ارسال |
| `/checkout/review` | بازبینی و پرداخت |
| `/order/confirmed` | تأیید سفارش |
| `/order/tracking` | پیگیری ارسال |

## ساختار

```
src/
  styles/global.css        توکن‌های رنگ، شعاع و فونت
  components/              Header، PageShell (پس‌زمینه/فوتر)، Action، OrderSummary، CheckoutProgress …
  pages/                   هر صفحه + ماژول CSS خودش
  data/products.ts         داده‌های شش شیرینی (متن، قیمت، مشخصات، تصاویر)
  state/cart.tsx           سبد خرید واقعی (افزودن، تعداد، حذف، جمع کل)
scripts/                   دانلود asset ها از فیگما
```

## نکته‌ها

- چیدمان دسکتاپ با اندازه‌ها و فاصله‌های فریم ۱۴۴۰ فیگما ساخته شده و در عرض‌های کمتر (تبلت/موبایل) ستون‌ها زیر هم می‌روند.
- ترکیب‌بندی صفحهٔ محصول (شیرینی معلق، برچسب مواد، مدار) با مختصات دقیق فیگما است و روی لپ‌تاپ‌های کوچک‌تر یکجا کوچک می‌شود.
- فایل فیگما برای «نیویورک رول پسته» صفحهٔ محصول چوکو بار ندارد؛ این محصول در کالکشن و سبد هست ولی لینک صفحه ندارد.
- صفحه‌های تأیید و پیگیری، مثل طرح، اطلاعات نمونهٔ ثابت سفارش CH-۲۰۴۸ را نشان می‌دهند (`src/data/order.ts`).
